# Галерейн зургууд

Энэ хавтсанд зураг хийхэд `/mn/gallery` дээр шууд гарна — код засах,
серверээ дахин асаах шаардлагагүй.

## Дараалал

Файлын НЭРЭЭР эрэмбэлэгдэнэ. Тиймээс урдаа `01-`, `02-` гэсэн дугаартай:
зургийн байрыг солихын тулд нэрийг нь өөрчилнө.

Зохиомжид **тав дахь нүд бүр өргөн** (2 багана, 16:10) болдог — өөрөөр
хэлбэл 1, 6, 11, 16 дахь зураг. Тэдгээр байранд **хэвтээ** зураг тавь;
босоо зураг тэнд дээд, доод талаа алдана. Бусад нүд босоо (4:5).

## Тайлбар (alt)

Дэлгэц уншигчид зориулсан тайлбар нь
`src/app/[locale]/(marketing)/gallery/page.tsx` доторх `ALT` жагсаалтад
файлын нэрээр холбогдоно. Шинэ файл нэмэхэд тэнд мөр нэмэх нь зүйтэй —
байхгүй бол «Twerk Mongolia» гэсэн ерөнхий тайлбар орно.

## Өгөгдлийн сан давамгайлна

Админаас (`gallery_items` хүснэгт) ГЭРЭЛ ЗУРАГ нэмсэн бол энэ хавтас
ажиллахаа болино. Хоёуланг нь зэрэг ашиглах боломжгүй: файл нь хурдан,
админ нь эрэмбэ, тайлбарыг нарийн удирдана.

Гагцхүү `.svg` заасан мөрийг ОРЛУУЛАГЧ гэж үзнэ. Үрийн өгөгдөл нь
`/media/studio-1.svg` … гэсэн зурсан дүрсийг байрлуулдаг бөгөөд тэдгээр
нь «энд зураг орно» гэж хэлэх зориулалттай. Тэднийг «дүүрсэн галерей»
гэж тооцвол жинхэнэ зураг хэзээ ч гарахгүй байлаа.
