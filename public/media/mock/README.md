# Түр өгөгдлийн зургууд

`supabase/mock-data.sql` нь эдгээр **яг эдгээр нэртэй** файлыг заана. Файлыг
энэ хавтсанд хийхэд хуудсан дээр шууд гарна — код засах, SQL дахин
ажиллуулах, серверээ дахин асаах шаардлагагүй.

Файл БАЙХГҮЙ бол эвдэрсэн зураг гарахгүй: `src/components/site/media.tsx`
серверт замыг шалгаж, олдохгүй бол монохром орлуулагч зурна. Тиймээс хэдийг
нь ч дурын дарааллаар солиж болно.

## Эдгээр нь хаанаас гарсан бэ

Бүгд `media-source/banners/` доторх ЖИНХЭНЭ гэрэл зургаас зүсэгдсэн (өмнөх
хувилбар нь `hero.jpg` -ийн хэвтээ зүсэлтүүд байсан бөгөөд бүгд ижилхэн
харагддаг байв). Зүсэлт бүрийн босоо байрлалыг гар аргаар биш, зургийн
нарийвчлалын нягтралаар автоматаар олсон — субьект дээр төвлөрнө.

Харьцаа нь хуудсан дээр харагдах хэлбэртэйгээ тааруулсан: багш 4:5,
хичээл 3:4, бараа 4:5. Гэхдээ `object-fit: cover` тул ямар ч харьцаатай
зураг эвдэрхгүй — зүгээр л илүү тайрагдана.
