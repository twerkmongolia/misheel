# Түр өгөгдлийн зургууд

> **Эдгээр файлууд аль хэдийн БЭЛЭН.** `hero.jpg` -ээс хөндлөн гулсуулж
> зүссэн бодит гэрэл зургууд — зүсэлт бүрд өөр бүжигчид тохирсон тул
> хайрцгууд ялгаатай харагдана. Загвар харах зорилгоор л хийсэн: жинхэнэ
> зургаа ижил нэрээр дарж хуулбал шууд солигдоно, SQL ч код ч хөндөх
> шаардлагагүй.

`supabase/mock-images.sql` -ийг ажиллуулсны дараа өгөгдлийн сан эдгээр
**яг эдгээр нэртэй** файлыг заана. Файлыг энэ хавтсанд хийхэд хуудсан дээр
шууд гарна — код засах, SQL дахин ажиллуулах, серверээ дахин асаах
шаардлагагүй.

Файл БАЙХГҮЙ бол эвдэрсэн зураг гарахгүй: `src/components/site/media.tsx`
серверт замыг шалгаж, байхгүй бол монохром орлуулагч зурна. Тиймээс хэдийг
нь ч дурын дарааллаар нэмж болно.

## Хэмжээ

Урт талаараа **2000px орчим**, 500KB-аас бага. Next.js өөрөө хэмжээг нь
тааруулах ч эх файл жижиг байх тусмаа сайн.

Харьцаа таарахгүй байсан ч болно — зураг `object-cover` -ээр төвөөсөө
зүсэгдэнэ. Гэхдээ босоо нүдэнд хэвтээ зураг тавибал хажуу талууд нь
их хэмжээгээр хасагдана.

## Жинхэнэ ажиллагаа

Энэ хавтас бол ЗАГВАР ХАРАХАД зориулагдсан. Байнгын зургийг `/admin`
доторх багш, барааны хуудаснаас байршуулна — тэндээс Supabase Storage
руу орж, өгөгдлийн санд бүтэн URL бичигдэнэ.
