# Хуудасны туузны зургууд

Энэ хавтсанд **яг эдгээр нэртэй** файл хийхэд тухайн хуудас туузтай болно —
код засах, серверээ дахин асаах шаардлагагүй.

| Файл               | Хуудас              | Хаяг                |
| ------------------ | ------------------- | ------------------- |
| `schedule.jpg`     | Бүртгэл / Хуваарь   | `/mn/schedule`      |
| `shop.jpg`         | Дэлгүүр             | `/mn/shop`          |
| `about.jpg`        | Бидний тухай        | `/mn/about`         |
| `classes.jpg`      | Хичээлүүд           | `/mn/classes`       |
| `instructors.jpg`  | Багш нар            | `/mn/instructors`   |
| `gallery.jpg`      | Галерей             | `/mn/gallery`       |
| `faq.jpg`          | Түгээмэл асуулт     | `/mn/faq`           |
| `contact.jpg`      | Холбоо барих        | `/mn/contact`       |

Файл БАЙХГҮЙ бол хуудас эвдрэхгүй — өмнөх гарчигтайгаа хэвээр үлдэнэ
(§ `src/components/site/PageBanner.tsx`). Тиймээс хэдийг нь ч дурын
дарааллаар нэмж болно. Нэгийг нь хийж үзээд таалагдвал үлдсэнийг нь нэм.

## Ямар зураг тохирох вэ

Тууз нь **өндөр нь тогтмол, өргөн нь дэлгэцийн хэрээр** сунадаг цонх юм
(`clamp(15rem, 34vw, 26rem)` — утсан дээр ~240px, дэлгэц дээр ~416px).
Зураг нь `object-fit: cover` — өргөн дэлгэцэд ДЭЭД, ДООД тал нь тайрагдана.

Тиймээс:

- **Хэвтээ** зураг сонго. Босоо зураг тайрагдахдаа толгойгоо алддаг.
- Гол дүр нь **голдоо, ЭСВЭЛ баруун талдаа** байг — гарчиг нь зүүн доод
  буланд сууна. Зүүн доод талд царай, гол хөдөлгөөн байвал текст дарна.
- Доод хэсэг нь **бараан уналтад** ордог. Тэнд нарийн дэлгэрэнгүй зүйл
  (жижиг бичиг, хээ) байвал далдлагдана.
- Урт талаараа **2400px орчим**, 500KB-аас бага байвал тохиромжтой.
- Өргөтгөл нь заавал `.jpg`. `.webp` / `.png` хэрэглэх бол
  `src/components/site/PageBanner.tsx` доторх замын өргөтгөлийг зас.

## Хэрхэн хийх вэ

Finder дээр энэ хавтсыг нээгээд файлуудаа зөв нэрээр хуулж хий:

```
misheel/public/media/banners/
```

Терминалаас бол:

```sh
cp ~/Downloads/<файл>.jpg public/media/banners/shop.jpg
```

### Ашиглагдаагүй эх зургууд

`media-source/banners/` дотор дараах нь сул байна — `schedule`, `faq` -г
солиход, эсвэл дээрхийг өөрчлөхөд ашиглаж болно:

| Файл                     | Хэмжээ      | Юу харагдах                          |
| ------------------------ | ----------- | ------------------------------------ |
| `IMG_5407.jpeg`          | 9504×6336   | RED AJIP тайз, өргөн                 |
| `Facetune_17-05-2026`    | 6143×4095   | RED AJIP тайз, үзэгчдийн гар         |
| `Facetune_03-06-2026`    | 4116×5146   | ZUNII ZUGAA тайз                     |

> Гурав нь өөр арга хэмжээний нэрийг (RED AJIP, ZUNII ZUGAA) LED дэлгэц
> дээрээ томоор харуулдаг. Тиймээс `contact` -д өөрсдийнх нь брэнд
> харагддаг `Facetune_26-04-2026` -г сонгосон.

### Шинэ эх зургаас тууз зүсэх

```sh
python3 - <<'PY'
from PIL import Image
im = Image.open('media-source/banners/<файл>.jpeg').convert('RGB')
W, H = im.size
band = round(W / 3.33)       # туузны харьцаа
top  = 700                   # босоо байрлалыг энд тохируулна (0..H-band)
im.crop((0, top, W, top + band)).save(
    'public/media/banners/<хуудас>.jpg', quality=84, optimize=True, progressive=True)
PY
```
