# «Бидний тухай» хуудасны зургууд

Энэ хавтсанд дараах **яг эдгээр нэртэй** файл хийхэд хуудсан дээр шууд
харагдана — код засах, серверээ дахин асаах шаардлагагүй.

| Файлын нэр          | Хаана гарах                | Тохирох хэлбэр      |
| ------------------- | -------------------------- | ------------------- |
| `team-lineup.jpg`   | Хуудасны эхний өргөн зураг | хэвтээ, 21:9 орчим  |
| `team-circle.jpg`   | «Twerk Mongolia» түүхийн хажууд | босоо, 4:5     |
| `team-row.jpg`      | «Заалнаас» эвлүүлгийн том нүд | хэвтээ, 4:3      |
| `trio.jpg`          | Эвлүүлгийн баруун дээд     | босоо эсвэл дөрвөлжин |
| `stage.jpg`         | Эвлүүлгийн баруун доод     | босоо эсвэл дөрвөлжин |

Файл байхгүй бол хуудас эвдрэхгүй — оронд нь абстракт орлуулагч зурагдана
(§ `src/components/site/media.tsx`).

Дэмжих өргөтгөл: `.jpg`. Өөр өргөтгөл (`.webp`, `.png`) хэрэглэх бол
`src/app/[locale]/(marketing)/about/page.tsx` доторх `PHOTOS` жагсаалтын
замыг нь зас.

## Хэмжээ

Урт талаараа **2000px орчим**, 500KB-аас бага байвал тохиромжтой. Үүнээс том
файл хуудсыг удаашруулна — Next.js өөрөө хэмжээг нь тааруулж өгөх ч эх файл
нь жижиг байх тусмаа сайн.
