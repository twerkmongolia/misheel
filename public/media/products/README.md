# Барааны зураг

Энд барааны **slug**-аар нэрлэсэн зураг тавихад демо горимд шууд харагдана —
сервер дахин асаах шаардлагагүй, хуудсаа сэргээхэд л хангалттай.

Ижил нэртэй файлыг шинээр солиход ч ажиллана: URL-д файлын өөрчлөгдсөн
хугацааг залгадаг тул Next-ийн зургийн кэш хуучин хувилбарыг барьж үлдэхгүй.

```
crop-top.jpg      → Crop top
joggers.jpg       → Joggers өмд
knee-pads.jpg     → Өвдөгний хамгаалалт
tote-bag.jpg      → Tote цүнх
```

Нэг бараанд олон зураг: ард нь дугаар нэмнэ — `crop-top-2.jpg`, `crop-top-3.jpg`,
`crop-top-4.jpg`. Эхний зураг нь жагсаалтад харагдана.

Дэмжих өргөтгөл: `.jpg` `.jpeg` `.png` `.webp` `.avif`
Санал болгох хэмжээ: квадрат, 1200×1200 орчим.

Зураг байхгүй бол абстракт орлуулагч гарна — хуудас хэзээ ч хоосон харагдахгүй.
